Read `.github/ISSUE_TEMPLATE/standard-issue-template.md` before drafting an issue. Include every section, using `N/A` when necessary. Add affected routes, files, browsers, devices, locales, reproduction steps, screenshots, and expected behavior when relevant. Use a clear, searchable title and only labels that already exist. Include the required `Model: Sonnet|Opus | Review effort: low|medium|high` recommendation using the guidance in `AGENTS.md`.
